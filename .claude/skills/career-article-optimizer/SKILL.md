# 职场心得文章优化器

基于4类职场文写作框架和故事化实操技巧，对现有职场文章进行诊断、优化、输出。

核心原则：职场文受众核心需求是「有用、能落地、有共鸣」，拒绝空泛鸡汤，兼顾干货密度和可读性，适配自媒体传播。

## 一、输入规范

用户输入格式：`<文章路径> [优化要求]`

- **文章路径**（必填）：Markdown 文件的绝对或相对路径
- **优化要求**（可选）：如"更接地气"、"加故事"、"精简到1000字"、"面向新人"等

示例：
- `@src/eq/01.md 优化一下，更接地气一些`
- `/path/to/article.md 帮我补充故事案例`
- `article.md 改写成避坑提醒风格`

## 二、4类职场文写作框架速查

优化前先判断文章属于哪种类型，对照对应框架检查完整性：

### 框架1：干货落地型

**适配选题**：升职加薪、沟通技巧、需求对接、年终总结等

| 步骤 | 要点 | 字数 |
|------|------|------|
| 开头 | 直击痛点，引发共鸣（场景/反问/数据） | 100字内 |
| 中间 | 3-4个分点，每点配「方法+案例+避坑」 | 核心 |
| 结尾 | 总结核心+引导互动 | 50-80字 |

分点逻辑：先讲"怎么做"，再讲"为什么这么做"，最后加"避坑提醒"。

### 框架2：经验分享型

**适配选题**：学生思维、新人管理、跳槽择业、职场成长等

| 步骤 | 要点 | 字数 |
|------|------|------|
| 开头 | 个人经历代入，拉近距离（真实经历引发共鸣） | 100字内 |
| 中间 | 2-3个核心经历+感悟+实操方法 | 核心 |
| 结尾 | 情感共鸣+价值升华+引导互动 | 50-80字 |

逻辑：经历（踩坑/成功）→ 反思（问题所在）→ 方法（可落地，普通人能复制）。

### 框架3：避坑提醒型

**适配选题**：职场人情世故、学生思维、需求踩坑、晋升误区等

| 步骤 | 要点 | 字数 |
|------|------|------|
| 开头 | 直接点出"坑"，制造焦虑感（戳中痛点） | 80字内 |
| 中间 | 3-5个坑，每个配「表现+危害+规避方法」 | 核心 |
| 结尾 | 总结提醒+引导互动 | 50字内 |

逻辑：先描述"坑的具体表现"（让受众对号入座）→ 讲"危害"→ 给"解决方案"。

### 框架4：心态共鸣型

**适配选题**：职场内耗、低谷期、情绪管理、格局提升等

| 步骤 | 要点 | 字数 |
|------|------|------|
| 开头 | 场景代入，引发情绪共鸣（细节打动） | 100字内 |
| 中间 | 情感共鸣+正向引导+简单方法 | 核心 |
| 结尾 | 价值升华+温暖鼓励+引导互动 | 60字内 |

逻辑：共情（理解情绪）→ 拆解根源（如"内耗核心是太在意别人评价"）→ 给1-2个简单调整方法。

## 三、故事化写作技巧检查清单

职场文的故事化，核心是「用真实职场故事承载干货/观点」，不喧宾夺主、不脱离干货。逐项检查：

### 故事选择
- [ ] 故事是否真实接地气？（拒绝"入职3月升总监"式悬浮剧情）
- [ ] 故事是否服务于核心观点？（非纯讲故事无干货输出）
- [ ] 是否选对了故事类型？
  - 踩坑类：适配避坑、学生思维、管理误区
  - 成长类：适配升职加薪、个人成长
  - 共鸣类：适配内耗、心态、沟通

### 故事结构
- [ ] 是否遵循「痛点场景→冲突转折→解决过程→核心感悟」？
- [ ] 是否有转折而非平铺直叙？
- [ ] 单篇故事是否控制在150-250字？（全文故事占比不超过40%）

### 故事语言
- [ ] 是否用"情绪、动作、对话"增强画面感？（不说"我很紧张"，说"手心冒冷汗，攥着笔记本的手都在抖"）
- [ ] 语言是否通俗接地气？（不说"优化沟通逻辑"，说"找对汇报方法，少做无用功"）

### 故事与干货衔接
- [ ] 故事结尾是否自然引出干货观点？
- [ ] 干货方法是否围绕故事展开？（避免"故事归故事，干货归干货"脱节）
- [ ] 衔接方式是否自然？（故事引出干货 / 干货穿插故事）

### 故事避坑
- [ ] 故事是否喧宾夺主？（故事太长、细节太杂，盖过干货）
- [ ] 是否刻意煽情？（不说"我太委屈了"，说"那次被批评后，我冷静反思，发现了自己的问题"）
- [ ] 故事是否贴合选题？（强相关，不写无关职场矛盾）

### 不同框架的故事化适配
- [ ] 干货落地型：每个干货点配1个简短小故事（50-100字）
- [ ] 经验分享型：以自身完整故事为线索，穿插干货方法
- [ ] 避坑提醒型：每个"坑"配1个踩坑小故事
- [ ] 心态共鸣型：用故事代入情绪，引发共情，再给出调整方法

## 四、通用写作技巧检查清单

无论哪种框架，都要逐项检查：

### 标题（决定点击率）
- [ ] 是否包含痛点+利益点+稀缺性？
- [ ] 关键词是否前置？（让受众一眼看到价值）
- [ ] 标题公式检查（三选一）：
  - 痛点+解决方案：如"职场内耗严重？3个简单方法，彻底摆脱内耗"
  - 经历+成果：如"从新人到管理，我踩过的3个坑，帮你少走2年弯路"
  - 数字+价值：如"3个向上沟通技巧，让领导主动重视你"
- [ ] 是否避免了夸大？（不说"看完这篇就能升职加薪"）

### 开头（3秒抓住注意力）
- [ ] 是否在100字内直击痛点？
- [ ] 是否避免了铺垫和绕弯？
- [ ] 开头方式检查（四选一）：
  - 场景代入（最易共鸣）
  - 反问提问（引发思考）
  - 个人经历（拉近距离）
  - 数据/现象（增强说服力）

### 中间内容
- [ ] 每个方法是否具体可操作？（不说"要学会沟通"，说"汇报用'结果+过程+需求'逻辑"）
- [ ] 语言是否通俗？（拒绝专业术语，像聊天一样写）
- [ ] 结构是否清晰？（分点+小标题，每段不超过3行）
- [ ] 是否每个观点配1个简短案例？（控制在50字内）
- [ ] 单篇字数是否控制在800-1200字？

### 结尾（引导互动，提升账号权重）
- [ ] 是否总结了核心价值？
- [ ] 是否引导了互动？（点赞/收藏/评论/关注）
- [ ] 结尾方式检查（三选一）：
  - 提问互动：结合选题提问
  - 福利引导：给出免费福利引导收藏
  - 情感鼓励：温暖鼓励引发共鸣
- [ ] 是否避免了草草收尾或新增无关内容？

### 整体避坑
- [ ] 是否拒绝了空泛鸡汤？（所有观点都配有方法）
- [ ] 是否避免了负能量？（可以讲踩坑/内耗，但结尾正向引导）
- [ ] 是否避免了夸大？（客观表述方法效果）
- [ ] 是否贴合目标受众？（新人→基础方法，中层→统筹带队技巧）

## 五、执行流程

### 步骤1：读取并分析文章

1. 用 Read 工具读取文章全文
2. 识别文章类型（干货落地/经验分享/避坑提醒/心态共鸣）
3. 对照对应框架检查结构完整性，标记缺失或薄弱的环节
4. 用故事化技巧检查清单逐项扫描，标记问题点
5. 用通用写作技巧检查清单逐项扫描，标记问题点
6. 根据用户额外的优化要求，标记需要调整的内容

输出诊断报告：

```
### 文章诊断报告

**文章类型**：{类型}
**匹配框架**：{框架名称}
**当前字数**：{字数}
**故事占比**：{百分比}

**结构完整性**：
- ✅ {已具备的步骤}
- ❌ {缺失的步骤}
- ⚠️ {存在但薄弱的步骤}

**故事化问题**：
- {问题1}
- {问题2}

**写作技巧问题**：
- {问题1}
- {问题2}

**用户要求调整**：
- {要求1}
```

### 步骤2：制定优化策略

根据诊断结果，制定优化方案。优化不是重写，而是在保留原文核心内容的基础上改进：

| 问题类型 | 优化策略 |
|---------|---------|
| 缺失框架步骤 | 补充对应步骤的内容，风格与原文一致 |
| 开头不够吸引 | 用4种开头方式之一重写，100字内直击痛点 |
| 故事缺失或薄弱 | 补充真实接地气的职场故事，遵循4步结构 |
| 故事与干货脱节 | 添加衔接句，让故事自然引出观点 |
| 案例不足 | 为每个观点补充具体可操作的案例 |
| 内容空泛/鸡汤 | 将空泛建议替换为具体方法+话术 |
| 标题不够吸睛 | 用3种标题公式之一重写 |
| 结尾缺乏互动 | 补充总结+互动引导 |
| 内容冗长 | 删除重复表述，精简故事至150-250字 |

### 步骤3：执行优化

用 Edit 工具逐步修改文章。优先处理结构性问题，再处理故事化和细节问题。

**优化原则**：
- 保留原文的核心观点和信息，不改变文章主旨
- 保持原文的语言风格（除非用户要求改变风格）
- 故事要真实接地气，拒绝悬浮剧情和刻意煽情
- 每次修改聚焦一个问题，避免大段重写
- 单篇字数控制在800-1200字
- 如果用户指定了字数目标，通过精简或补充调整篇幅

**注意 frontmatter**：如果原文有 YAML frontmatter（`---` 之间的内容），不要修改或删除它。

### 步骤4：输出优化报告

优化完成后，输出报告：

```
### 优化完成

**优化项**：
1. {优化项1：做了什么，为什么}
2. {优化项2：做了什么，为什么}
3. ...

**框架补全**：
- ✅ 已补充：{补充的步骤}

**故事化改进**：
- ✅ {改进项}

**写作技巧改进**：
- ✅ {改进项}

**字数变化**：{原字数} → {新字数}
```

## 六、选题专属适配建议

| 选题 | 推荐框架 | 核心写法 | 故事化适配 |
|------|---------|---------|-----------|
| 学生思维 | 避坑提醒型 | 表现+危害+规避方法，开头场景代入 | 加1个踩坑故事增强共鸣 |
| 升职加薪/年终总结 | 干货落地型 | 可操作方法+数据案例，标题"数字+价值" | 每个干货点配1个简短故事 |
| 新人做管理 | 经验分享型 | 管理踩坑+带队方法，结尾引导领模板 | 以自身管理故事为线索 |
| 沟通协作/需求对接 | 干货落地型 | 分点写沟通技巧，配具体话术+案例 | 加入沟通小故事佐证 |
| 个人成长/心态 | 心态共鸣型 | 情绪共鸣+简单调整方法，语言温柔 | 用自身心态成长故事引发共情 |

## 七、常见优化模板

### 重写开头（场景代入型）

```
{描述职场常见痛点场景}。其实，{核心方法/观点}才是关键。本文将{文章价值承诺}，帮你{具体行动结果}。
```

### 重写开头（经历代入型）

```
从{起点}到{终点}，我用了{时间}，踩过{数量}个坑——{简述核心坑}。今天把经验整理出来，帮你{利益承诺}。
```

### 添加故事（4步结构）

```
**痛点场景**：{描述具体困境，用细节增强画面感}
**冲突转折**：{关键事件触发反思/改变}
**解决过程**：{用了什么方法，具体怎么做}
**核心感悟**：{一句话提炼观点，自然衔接干货}
```

### 故事衔接干货

```
正是踩了这个{XX}的坑，我总结出{N}个{XX}技巧，帮你避免走弯路：
```

### 补充互动结尾

```
{1句总结核心}。你{提问引导}？评论区留言，{互动承诺}。
```
